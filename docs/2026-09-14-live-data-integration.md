# 知辨真实数据接入记录

## 已接入

- 本机服务通过已安装的官方知乎 CLI 调用站内搜索；密钥只由 CLI 从凭据库或临时进程环境读取，没有写入代码、配置或浏览器。
- 2026-09-14 实测：“该不该辞职全职带娃”“第一份工作 高薪 成长”与“胖东来 四年 学员制 招工”均返回 10 条来源，并各自选出三组已核对观点。
- 带娃场次：星澜／鑫妈辅娃记、晓君养娃日记／水刃木、元来时你／橙子汽水。
- 工作场次与今日热辩均保留六个来源 ID；以上是检索时的结果，不保证未来搜索排序不变。席位每次都要重新匹配来源 ID 与原句；不匹配就降级，不用虚构作者补位。
- “元来时你”是条件性观点，界面明确提醒同一回答也支持有可靠帮手时工作，避免把条件判断包装成绝对立场。

## 界面调整

- 姓名过长时截断，完整姓名保留在卡片与标题提示中；使用真实头像，加载失败回退首字头像。
- 首屏展示可追溯原句，长摘要可展开；摘要和原文明确区分。
- 背景卡只引用接口认证和回答中明确的本人自述；没有自述则不推断。
- 卡片新增服务端 DeepSeek 摘要；原文与来源弹窗展示接口返回正文，并保留知乎完整原文链接。
- 已发布题目按三回合呈现；来源失效时只保留仍能核对的回合，不产生空白席位或虚构内容。
- 标志按钮真正返回辩论，回顾页顶部标识同步更新。
- 调大手机席位和正文辅助文字，增加来源时间、缓存提示、加载和错误状态。
- 删除用于虚构人物的预设 AI 分析。AI 质询入口标明待接入。

## 验证与限制

- 32 项自动检查通过：状态转换、来源清洗、原句匹配、缓存、鉴权边界、错误收敛、真实页面 DOM 交互等。
- 本地真实接口已联调成功。`node tests/live-smoke.mjs` 可以单独验收真实接口到页面 DOM 的链路，可能消耗一次未缓存搜索调用。
- 本轮浏览器控制连接持续失败，已尝试重新初始化；没有完成浏览器截图与像素级响应式验收。DOM 测试不能替代视觉检查。
- 自由搜索已可用，但任意新问题的自动阵营分析与编排、实时 AI 质询仍未接入。
- `POST /api/summarize` 已通过 `deepseek-flash` 完成真实联调；密钥仅存在服务进程环境中，未写入仓库。
- 当前是单用户本机开发服务；不具备公网多用户身份隔离，不应直接部署为公共代理。
